# 图片处理工具

Windows 桌面图片处理软件。用户直接导入一张或多张图片，通过左侧导航选择处理功能。

作者：Konsheng

版本：v1.0.0

## 功能

- 左侧可折叠导航栏
- 综合处理
- 尺寸处理
- 格式转换
- 图片压缩
- LOGO叠加
- LOGO 素材库多选叠加
- LOGO 单图覆盖
- 水印
- 处理后效果预览
- 批量处理取消
- 浅色、暗色、跟随系统主题
- 关于页
- 支持图片文件选择、文件夹选择和拖拽导入
- 支持 JPG、PNG、WEBP、保持原格式
- 支持 1–100 手动质量压缩，默认质量为 95
- 支持真实压缩画质和预计输出大小预览
- 综合处理页显示累计处理图片数和累计净节省空间
- 输出文件不覆盖原图，重名时自动加序号

## 输出尺寸

综合处理和尺寸处理支持以下预设规格：

- 800×800 px
- 1000×1000 px
- 1200×1200 px
- 1440×1440 px
- 1920×1920 px
- 自定义宽高

默认规格为 1440×1440 px。尺寸处理会等比缩放图片，不裁切主体，不足区域使用白色背景补齐。自定义尺寸单边最大 16384 px，总像素不超过 6400 万，以避免过大画布占用异常内存。

## 独立功能页

- 综合处理：尺寸、格式、压缩、LOGO、水印可组合设置
- 尺寸处理：只调整尺寸，保持原格式；BMP 输出为 JPG
- 格式转换：只转换格式，保持原尺寸
- 图片压缩：只压缩，保持原尺寸和原格式；BMP 输出为 JPG
- LOGO叠加：从内置素材库多选叠加图，保持原尺寸和原格式；BMP 输出为 JPG
- 水印：添加文字水印或图片水印，保持原尺寸和原格式；BMP 输出为 JPG

## 压缩质量

`综合处理` 和 `图片压缩` 页面支持 1–100 的质量滑块和数字输入，默认质量为 95。该质量值适用于 JPG/WEBP；当任务全部输出为 PNG 时会隐藏质量设置，PNG 始终保持无损编码；混合格式批量任务仍会保留质量设置。预览会按当前参数进行真实编码，并显示预计输出大小。压缩只改变编码参数，不会自动降低图片分辨率。

## LOGO 素材库

内置 LOGO/叠加图素材文件夹：

```text
assets/logos/
```

支持格式：

- PNG
- JPG
- JPEG
- WEBP

透明 PNG 效果最好。素材按文件名排序后显示为可多选网格；网格会根据可用宽度和素材数量自动调整高度，最多直接显示两行，更多素材使用内部滚动。处理时会按网格顺序逐层叠加。素材会自动缩放到当前图片尺寸，并从 `(0, 0)` 直接覆盖合成。

在 `综合处理` 和 `LOGO叠加` 页面中，LOGO 支持“全局默认 + 单图覆盖”。全局勾选和当前网格选择作为默认规则；选中图片后可以使用：

- `应用到选中图片`：让选中的主图使用当前选中的 LOGO 素材
- `选中图片不叠加`：让选中的主图跳过 LOGO
- `恢复默认`：让选中的主图重新跟随全局默认

图片列表中的 `LOGO` 列会显示每张图当前规则：`默认`、`不叠加`、`自定义：N个`。批量处理和右侧预览都会按每张图片自己的最终规则执行。

旧路径 `assets/logo.png` 会作为兼容备用资源保留。新版优先读取 `assets/logos/`。

## 水印

独立的 `水印` 页面和 `综合处理` 中的水印功能默认关闭，可分别在 `设置 > 独立页面` 和 `设置 > 综合处理功能` 中开启，两者互不影响。处理顺序为：尺寸处理、LOGO叠加、水印、格式转换、压缩保存。

水印类型：

- 文字水印：支持文字内容、字号、颜色、透明度、九宫格位置、自定义坐标、边距、旋转角度、平铺
- 图片水印：选择本地水印图片，支持缩放比例、透明度、九宫格位置、自定义坐标、边距、旋转角度、平铺

默认文字为 `Konsheng`，默认位置为右下，默认透明度为 35%，默认边距为 40 px，默认角度为 0 度。输入 `-30` 或 `30` 可以生成斜向水印。

水印可以在右侧预览中拖拽定位。非平铺水印拖拽后会切换为自定义坐标；平铺水印拖拽后会调整平铺起始位置。平铺模式支持水平间距、垂直间距、起始X、起始Y。

## 预览与取消

每个功能页右侧显示全高固定预览侧栏。左侧设置和处理结果可以滚动，右侧预览不会跟随滚动离开视口。预览侧栏支持动画折叠，折叠后右侧保留窄栏展开按钮，折叠状态在所有功能页之间同步。导入并选中图片后，预览会按当前页面设置显示处理后效果。

在 `综合处理` 和 `图片压缩` 页面中，预览会在后台使用当前参数进行真实编码，再把编码结果重新解码显示，同时给出原始大小、预计输出大小、缩减或增大比例，以及实际采用的质量。预览使用 300ms 防抖并只保留最新请求，不会保存文件。

批量处理时可以点击 `取消处理`。软件会等待当前图片处理完成，再停止后续任务；未开始的图片会标记为 `已取消`。

## 累计处理统计

`综合处理` 页面顶部会汇总所有功能页成功生成的图片数量，并按“源文件总大小 - 输出文件总大小”显示累计净节省空间；如果输出文件总量更大，则显示累计净增加空间。预览、处理失败和尚未开始的取消任务不会计入。

累计数据只保存处理次数、源文件总字节和输出文件总字节，不保存文件名或路径。每成功生成一张图片都会立即写入当前 Windows 用户配置，因此关闭软件再打开后仍会继续累计。

## 设置、功能开关与主题

左侧导航底部提供 `设置` 页面，功能开关分为两组：

- `独立页面`：控制 `综合处理`、`尺寸处理`、`格式转换`、`图片压缩`、`LOGO叠加` 和 `水印` 在左侧导航中的入口。
- `综合处理功能`：单独控制综合处理页面中的尺寸、格式、压缩、LOGO 和水印。

两组开关互不影响。例如可以隐藏独立的 `图片压缩` 页面，同时保留综合处理中的压缩功能；也可以关闭综合处理中的压缩功能，同时继续使用独立页面。独立水印页面和综合处理水印默认关闭，其余开关默认开启。首次从旧版本升级时，原功能开关状态会分别复制给两组，此后各自独立保存。开关状态会保存到当前 Windows 用户配置中，下次启动自动恢复。`设置` 和 `关于` 始终保留，所有独立页面关闭后仍可重新开启。

主题支持：

- 浅色
- 暗色
- 跟随系统

主题选择会保存到当前 Windows 用户配置中，下次打开软件时自动恢复。

## 关于

左侧导航底部提供 `关于` 页面，显示软件名、作者、版本、本地处理与原图安全说明，并提供项目主页、最新版本、问题反馈和复制版本信息入口。需要联网的入口只会在用户点击后通过默认浏览器打开。

```bat
python -m unittest discover -s tests -v
```

## 打包

确认 `assets/logos/` 中至少有一个支持格式的素材后，执行：

```bat
build.bat
```

打包命令使用：

```bat
python -m PyInstaller --noconfirm --clean image_tool.spec
```

输出文件位于：

```text
dist/图片处理工具.exe
```

## GitHub Actions 发布

仓库包含 Release 工作流，支持推送 `v*` 标签自动发布，也支持在 GitHub Actions 页面手动运行。

自动发布示例：

```bat
git tag v1.0.0
git push origin v1.0.0
```

手动发布：

1. 打开 GitHub 仓库的 Actions 页面
2. 选择 `Release`
3. 点击 `Run workflow`
4. 输入版本标签，例如 `v1.0.1`

Release 会上传：

- `图片处理工具.exe`
- `图片处理工具-版本号-windows.zip`
